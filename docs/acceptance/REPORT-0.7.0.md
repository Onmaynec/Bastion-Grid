# Проверка версии 0.7.0

Профиль local-lab, схема 3. Полное ТЗ OMEGA не принято.

Набор: 163 unit/integration/HTTP/contract теста. Новые проверки покрывают атомарный импорт, повтор и конфликт, конкурентную дедупликацию, восстановление после открытия БД, формат/лимиты, provenance и приоритет, роли/tenant/assigned_only, назначение с учётом scope, сроки и просрочку, версии, переходы, полномочия терминальных решений и evidence того же/другого актива.

OpenAPI: 43 операции. Браузерный сценарий расширен до 12 разделов, импортом находки, повтором без дубля, назначением и сроком исправления, просмотром provenance. Результаты полного прогона будут добавлены после CI.

CycloneDX/SPDX, CMDB/webhooks, внешняя база CVE, reconciliation и автоматическое подтверждение по свежему скану отсутствуют. Приоритет не является CVSS/EPSS. Формальные AT: 0/192; OMEGA E2E: 0/16.
