Первая лабораторная версия: активы, события, правила, алерты, кейсы, доказательства и два независимых согласования. 8 разделов SOC-консоли, OpenAPI, verifier, backup и 43 теста.

Запуск: Python 3.12+, `python -m bastion init`, затем `python -m bastion serve --lab`. Адрес: http://127.0.0.1:8080. Демонстрация: `python tools/demo.py`.

Это предварительный релиз исходников, не готовый enterprise-продукт и не выполнение всего ТЗ. Реальное реагирование отключено. OIDC/MFA, PostgreSQL, подписанные агенты, HA/DR и OMEGA-подсистемы ещё не реализованы. Базовый браузерный сценарий пройден в CI; полный аудит доступности ещё не выполнен. Подробности и матрица всех требований находятся в документации.
