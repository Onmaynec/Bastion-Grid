## BASTION GRID 0.6.0 — Доказательства и жизненный цикл заявок

- Отказ в согласовании с причиной: независимый admin/lead переводит ожидающую заявку в REJECTED.
- Отмена инициатором или руководителем: pending/approved → CANCELLED, голоса сохраняются.
- If-Match, проверка TTL и scope внутри транзакции; конкурентные операции не перезаписывают друг друга.
- Фоновое сохранение EXPIRED для просроченных pending/approved, до 100 заявок за цикл, однократный аудит перехода.
- В консоли добавлены отказ, отмена и карточка с причиной завершения; завершённые состояния не подменяются истечением TTL.
- Offline verifier строго проверяет структуру, seq, уникальность evidence, Base64, размер и checkpoint. Ошибки CLI возвращают JSON и код 1 без traceback.
- Связи evidence.acquired проверяются через индекс за один проход по аудиту вместо повторного сканирования истории для каждого доказательства.
- 40 операций OpenAPI и 146 автоматизированных тестов; браузерный сценарий проверяет отказ и отмену согласованной заявки.

Обновление: остановите сервер, сохраните backup и запустите новую версию без init. Схема остаётся 3. Инструкция: docs/runbooks/RESPONSE_EVIDENCE.md.

Предварительный релиз локального стенда. Исполнение действий на устройствах отключено. PKI/KMS, цифровые подписи, WORM, MFA и agent receipts не реализованы; полное ТЗ OMEGA не завершено.
