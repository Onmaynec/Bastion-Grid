## BASTION GRID 0.2.0 — Управление доступом

- Учётные записи: создание, отзыв, ротация ключа и восстановление отозванного доступа через новый ключ.
- Срок ключа 60–86400 секунд. Новый ключ показывается один раз; старый ключ и все прежние сеансы отзываются при ротации.
- Ограничения по группам активов и четырём уровням чувствительности; режим доступа только к назначенным себе кейсам.
- Единая проверка scope для событий, алертов, кейсов, доказательств, заявок и replay. Ограниченный администратор не может расширить себе доступ.
- Список активных сеансов, выборочное завершение, Last seen. Обычный пользователь видит свои сеансы, полный администратор — сеансы тенанта.
- Версии политик учётной записи и If-Match. Изменение политики закрывает прежние сеансы; операции повторно проверяют доступ внутри транзакции.
- Миграция схемы 1 → 2, резервная копия перед миграцией, сохранение ключей и предметных данных. Старые браузерные сеансы закрываются.
- 10 разделов консоли, 29 операций OpenAPI, 68 автоматизированных тестов и расширенный браузерный сценарий.

Запуск: Python 3.12+, `python -m bastion init`, затем `python -m bastion serve --lab`. Адрес: http://127.0.0.1:8080. При обновлении существующей БД остановите старый процесс и запустите новую версию без повторного init.

Предварительный релиз исходников. Это локальный стенд, а не завершённое ТЗ OMEGA: OIDC/MFA, PostgreSQL/RLS, агенты, реальное реагирование и HA/DR ещё не реализованы. Архив содержит только отслеживаемые исходники; ключей и локальных БД в нём нет.
