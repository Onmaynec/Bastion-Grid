# Проверка версии 0.2.0

Дата: 14 ноября 2026 года. Профиль: local-lab; схема БД 2. Полное ТЗ OMEGA не принято.

Локально пройдены 68 unit/integration/HTTP/contract тестов на Python 3.12.14, а также compileall и JavaScript syntax check. Новые проверки покрывают выдачу/ротацию/отзыв ключей, запрет расширения scope ограниченным администратором, защиту последнего администратора, отсутствие ключей в списках/аудите, принудительное завершение сеансов, обновление политики во время запроса и межобъектные ссылки.

Миграционный тест создаёт БД по схеме 0.1.0, добавляет действующий ключ, сеанс и актив. После обновления ключ и актив сохраняются, старый сеанс закрыт, version=2. Проверено наличие исходной version=1 и старого сеанса в резервном snapshot. Повторный запуск не повторяет ALTER. Неизвестная будущая версия БД отклоняется.

Браузерный сценарий расширен: 10 разделов; создание ограниченной учётной записи; нулевые счётчики чужой группы; скрытая административная навигация для analyst; одноразовый показ ключа; ротация и отзыв; desktop/mobile; экранирование HTML. Результат удалённого CI фиксируется в GitHub Actions для конкретного commit; локальный Chromium по-прежнему ограничен окружением.

## Не проверено и не реализовано

PostgreSQL RLS, OIDC/PKCE, MFA, подписанные policy digests, региональный ABAC и полная независимая приёмка. Группы и чувствительность — application-level атрибуты текущего актива, а не классификатор содержимого событий. Полный аудит тенанта и управление глобальными правилами недоступны scoped identities: это запрет, а не реализация отредактированного audit export.

Формальные AT: 0 из 192; OMEGA E2E: 0 из 16. Локальное расширение IAM не завершает M1.
