# Проверка версии 0.6.0

Профиль local-lab, схема 3. Полное ТЗ OMEGA не принято.

Локальные проверки: 146 unit/integration/HTTP/contract тестов, compileall, синтаксис JavaScript. Новые тесты покрывают отказ, отмену согласованной заявки, роли/tenant, версии, причины, TTL, сохранение EXPIRED после перезапуска, однократный аудит, ограничение партии и гонки worker/согласования/отмены.

Verifier проверен на malformed JSON-структурах, неправильном Base64 и размере, seq, повторе evidence, некорректном/пустом checkpoint, неподдерживаемой подписи и ошибке CLI без traceback. Старые тесты целостности, экспорта и восстановления backup сохранены.

OpenAPI: 40 операций. Браузерный сценарий расширен отказом в заявке и отменой уже согласованной заявки. Удалённые результаты подтверждены ниже.

PKI/KMS, подписи, WORM, MFA, agent receipts, исполнение и rollback на устройствах отсутствуют. Hash chain без доверенного checkpoint не доказывает подлинность. Формальные AT: 0/192, OMEGA E2E: 0/16.
