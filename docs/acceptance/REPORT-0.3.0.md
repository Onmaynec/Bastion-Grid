# Проверка версии 0.3.0

Профиль local-lab, схема 3. Полное ТЗ OMEGA не принято.

Локально пройдены 100 unit/integration/HTTP/contract тестов на Python 3.12. Проверены привязка источника, scope collector, пауза, ротация, откат счётчиков, атомарные квоты, бесплатные дубликаты, UTC-окно, сохранение расхода при перезапуске и конкурентный приём.

Проверены изоляция ошибочного события, три попытки, отсутствие hot loop, откат частичных эффектов, единственный алерт при двух worker, ручной retry с версиями и backlog, tenant isolation и отсутствие текста исключения в DLQ. Ошибки SQLite не маркируют событие как poison. Миграционная fixture схемы 2 подтверждает сохранение живых сеансов, ключей, pending/done и исходного backup; повторный запуск идемпотентен.

Браузерный сценарий охватывает 11 разделов, регистрацию и паузу источника, квоты, ручной retry, управление доступом, экранирование HTML и ширину 390 px. Удалённый результат подтверждён ниже.

OpenAPI: 37 операций. Матрица сохраняет все 619 требований. Формальные AT: 0/192, OMEGA E2E: 0/16. mTLS, внешний брокер, PostgreSQL/RLS, OIDC/MFA, HA/DR и нагрузочные показатели RFP не реализованы и не проверены.
