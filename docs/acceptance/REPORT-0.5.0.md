# Проверка версии 0.5.0

Профиль local-lab, схема сервера 3. Полное ТЗ OMEGA не принято.

Локально пройдены 132 unit/integration/HTTP/contract теста, compileall и проверка синтаксиса JavaScript. Новые тесты: AND/OR, строгие ограничения предикатов, совпадение live/replay, объяснение условий, отсутствие побочных записей fixtures, границы наборов, tenant/scope denial, комбинированные фильтры, полуоткрытый интервал с часовыми поясами, ошибочные даты, курсор без повторов и совместимость старых правил.

OpenAPI содержит 38 операций. Браузерный сценарий расширен фильтрами, загрузкой 55 событий двумя страницами и созданием составного правила с проверкой двух примеров. Удалённые результаты будут добавлены после CI.

Не реализованы ClickHouse, временная корреляция, watermark, фоновые replay jobs и обязательный quality gate публикации. Формальные AT: 0/192, OMEGA E2E: 0/16. Производительность R1/R2 не заявляется.
