# Проверка версии 0.4.0

Профиль local-lab. Схема сервера 3, схема очереди collector 1. Полное ТЗ OMEGA не принято.

Локальные проверки: 120 unit/integration/HTTP/contract тестов; compileall; синтаксис JavaScript; генерация OpenAPI и матрицы. Новые проверки покрывают сохранение ID после перезапуска, cap по событиям и UTF-8 payload, конкурентную запись/отправку, потерю ACK, некорректный ACK, backoff, постоянную ошибку и ручной повтор, привязку очереди, CLI, запрет redirect/proxy и настоящий HTTP-путь с ротацией ключа.

API сохраняет 37 операций. Браузерный сценарий охватывает 11 разделов, источники, квоты, DLQ, доступ и 390 px. Удалённые результаты будут зафиксированы после CI.

Не проверены: 24-часовой ресурсный прогон, 48 часов offline, системные службы Windows/Linux, чтение security logs, шифрование spool, mTLS, подписанные обновления. Предел payload не является полным дисковым cap. Метрики очереди доступны локально; сервер не получает dropped/spool counters. Формальные AT: 0/192; OMEGA E2E: 0/16.
