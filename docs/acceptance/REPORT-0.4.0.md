# Проверка версии 0.4.0

Профиль local-lab. Схема сервера 3, схема очереди collector 1. Полное ТЗ OMEGA не принято.

Локальные проверки: 120 unit/integration/HTTP/contract тестов; compileall; синтаксис JavaScript; генерация OpenAPI и матрицы. Новые проверки покрывают сохранение ID после перезапуска, cap по событиям и UTF-8 payload, конкурентную запись/отправку, потерю ACK, некорректный ACK, backoff, постоянную ошибку и ручной повтор, привязку очереди, CLI, запрет redirect/proxy и настоящий HTTP-путь с ротацией ключа.

API сохраняет 37 операций. Браузерный сценарий охватывает 11 разделов, источники, квоты, DLQ, доступ и 390 px. Удалённые результаты подтверждены ниже.

Не проверены: 24-часовой ресурсный прогон, 48 часов offline, системные службы Windows/Linux, чтение security logs, шифрование spool, mTLS, подписанные обновления. Предел payload не является полным дисковым cap. Метрики очереди доступны локально; сервер не получает dropped/spool counters. Формальные AT: 0/192; OMEGA E2E: 0/16.

## Подтверждённый результат CI

[Tests #43566800010](https://github.com/Onmaynec/Bastion-Grid/actions/runs/43566800010), commit `cdda390`: все 120 тестов пройдены на Linux и Windows; Chromium-сценарий пройден. Генерация OpenAPI и матрицы не оставляет изменений. Новый collector проверен через CLI и настоящий HTTP, включая смену ключа.

Первый Windows-прогон выявил сравнение короткого имени временного каталога с полным. Тест исправлен: обе стороны сравнения используют resolve. Повторный полный прогон успешен. Скриншоты telemetry/mobile из первого браузерного прогона просмотрены; между прогонами изменён только тест путей.

[Source release #43566906231](https://github.com/Onmaynec/Bastion-Grid/actions/runs/43566906231) завершён успешно. [v0.4.0](https://github.com/Onmaynec/Bastion-Grid/releases/tag/v0.4.0) опубликован как prerelease из проверенного commit `cdda390`; приложены `Bastion-Grid-source.zip` и `SHA256SUMS`.
