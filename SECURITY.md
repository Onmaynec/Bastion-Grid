# Безопасность

Версия 0.7.0 предназначена только для локального стенда с синтетическими данными. Она не заменяет EDR/SIEM, не устанавливает системных служб и не выполняет действия на устройствах.

Не публикуйте ключи, cookies, реальные события и evidence в GitHub Issues. Сообщение об ошибке должно содержать версию, минимальный синтетический reproducer и ожидаемый результат. Если доступен GitHub Private Vulnerability Reporting, используйте его для чувствительных деталей. SLA обработки и внешняя сертификация не заявлены.

Известные границы защиты описаны в `docs/THREAT_MODEL.md` и `docs/acceptance/REPORT-0.7.0.md`.

Collector читает ограниченный набор сведений об ОС и пишет незашифрованный spool. Храните конфигурацию и ключ вне Git в каталоге с ограниченными правами; Windows ACL настраивается отдельно. Передача разрешена только через loopback, redirects/proxy отключены. Подписанная установка и защищённый enrollment отсутствуют.

Импорт Posture доступен полному admin/lead. Идентификатор уязвимости и имя сканера — непроверенные данные импортера. Fixed означает ручное решение с доказательством того же актива, а не подтверждение внешней системой.
